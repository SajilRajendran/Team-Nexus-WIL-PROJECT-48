# Team Nexus — WIL Project

**Group ID:** WIL PROJECT - 48
**Course:** COSC2669 

## Project Overview
A Retrieval-Augmented Generation (RAG) chatbot that helps residents and
prospective movers understand planning and public transport changes under
Victoria's Train and Tram Zone Activity Centres Program, making complex
government planning documents accessible through simple, everyday questions.
